2. THE TWO BUGS
================================================================================
Both are worth more than the scripts.

**Bug #1 — `set -e` swallowing your own error handler.** A failing command
substitution tripped `set -e` before the `if [ $rc -ne 0 ]` block below it could
run, so a connection failure printed nothing and exited 2. The intended
error message was unreachable code. This is the shell version of a guard that
cannot report the thing it exists to report, and it was sitting in the exact
path — "can we even reach the database?" — that CLAUDE.md finding #16 is about.

**Bug #2 — the empty-declarations file-role mix-up.** Your framing is right and
sharper than the finding itself:

    "the same shape as finding #5 (a check that silently measures the wrong
     thing) but inverted — instead of a false PASS, a false, total, RED"

And the observation underneath it is the one I want on record: **a false red is
cheap because someone investigates it; a false green is expensive because nobody
does.** You got that bug for free precisely because it failed loudly. The same
mistake in the passing direction would have shipped.

Note also *when* it appeared: on the normal case. No declarations is what every
run looks like until Phase 3. The bug was not in an edge case — it was in the
default path, and only the fact that it was catastrophically visible saved it.
